# 使用者自訂詞庫範例（見 core/src/user_phrases.rs 模組文件與 README.md）。
#
# 格式跟主詞庫一樣：注音<TAB>文字<TAB>詞頻，# 開頭或空白行會被忽略。
# 「注音」欄位其實只是查詢用的「捷徑代碼」，不必是文字真正的讀音——
# 你可以自由選一個好記、平常不常打到的音節組合當捷徑：
#   - 只打一個符號（例如只打聲母、不接介母／韻母／聲調）就是最短的
#     單一音節捷徑，打一個鍵就能叫出候選字；
#   - 想串多個音節當捷徑，音節之間要用一個空白分隔（跟主詞庫的多字詞
#     格式一樣），例如 "ㄉ ㄏ" 是先打 ㄉ、觸發音節邊界、再打 ㄏ 兩個
#     各自只有聲母的音節。
#
# 詞頻建議設高一點（例如 90000），確保排在候選字清單最前面；實際上
# 自訂詞一律會排在詞庫候選字之前，詞頻高低只影響自訂詞彼此之間的順序。
#
# 下面是範例（換成你自己的真實資料，這個檔案預設不會被版本控制追蹤，
# 見 .gitignore 的 /user_phrases.txt）：
ㄉ	台北市大安區羅斯福路四段1號	90000
ㄒ	王小明	90000
ㄉ ㄏ	0912-345-678	90000
